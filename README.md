# Healthcare-Fraud-Detection-Imbalanced-Data
A machine learning project for healthcare fraud detection on imbalanced datasets using Isolation Forest for noise filtering, Borderline-SMOTE for minority-class oversampling, and a soft voting ensemble of Random Forest, XGBoost, and LightGBM. Evaluates model performance using Precision, Recall, F1-Score, AUC-PR, and MCC.
