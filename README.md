# Healthcare Fraud Detection on Imbalanced Data

This project focuses on detecting fraudulent healthcare claims in highly imbalanced datasets using machine learning.

### Key Features
- Data preprocessing and missing-value handling
- Isolation Forest for noise and outlier filtering
- Borderline-SMOTE for minority-class oversampling
- Soft Voting Ensemble using Random Forest, XGBoost, and LightGBM
- Model evaluation using Precision, Recall, F1-Score, AUC-PR, and MCC

### Objective
To improve healthcare fraud detection by addressing class imbalance and reducing false-positive fraud predictions.

### Key Result
The proposed pipeline achieved a reported precision of **0.936** in the notebook's comparative analysis.

### Technologies
Python, Pandas, NumPy, Scikit-learn, XGBoost, LightGBM, and Imbalanced-learn.
